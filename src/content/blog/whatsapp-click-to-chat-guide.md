WhatsApp Click to Chat is a powerful but underused feature that lets you start a conversation with anyone on WhatsApp without having their number saved in your contacts. Despite being available for years, many people still do not know it exists or how to use it effectively.

This guide covers everything: what Click to Chat is, how the underlying `wa.me` links work, and how OPN Chat provides the simplest way to use this feature.

## What Is WhatsApp Click to Chat?

Click to Chat is WhatsApp's official feature that generates a link pointing to a specific phone number. When someone opens this link, WhatsApp launches a new conversation with that number — even if the number is not saved in their contacts.

The feature uses the URL format `wa.me/number`, where `number` is the full phone number in international format (country code + number, no plus sign, no spaces, no dashes).

For example, to message the Brazilian number +55 11 91234-5678, the Click to Chat link would be:
`wa.me/5511912345678`

## How wa.me Links Work

The `wa.me` domain is owned by WhatsApp (Meta). When you navigate to a wa.me link:

1. Your browser sends a request to WhatsApp's servers.
2. WhatsApp verifies the phone number format.
3. You are redirected to the WhatsApp app (on mobile) or WhatsApp Web (on desktop) with a new chat window open for that number.
4. You can start typing and sending messages immediately.

### Adding a Pre-Filled Message

You can also append a pre-filled message to the link using the `?text=` parameter:

`wa.me/5511912345678?text=Hello%2C%20I%20am%20interested%20in%20your%20listing`

When the chat opens, this message will appear in the text field, ready for the user to send. This is especially useful for business contexts where you want to provide context right away.

- **Sales inquiries** — Add a "Chat with us on WhatsApp" button to your product pages
- **Event coordination** — Share a WhatsApp link in event invitations for quick communication

## The Problem with Manual wa.me Links

While Click to Chat is powerful, using it manually has friction:

- You have to **remember the URL format** and construct it correctly
- You must **strip the + sign, spaces, and dashes** from the phone number
- On mobile, **typing a URL** is awkward and error-prone
- There is **no way to pre-fill a message** easily without URL encoding

## Is Click to Chat the Same as WhatsApp Business API?

No. Click to Chat (wa.me links) is a free, consumer-facing feature available to every WhatsApp user. The WhatsApp Business API is a separate, paid product for businesses that need automated messaging, chatbots, and CRM integrations at scale.
