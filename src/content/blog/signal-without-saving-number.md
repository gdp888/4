## How Does It Work?

Signal uses a web link format: `signal.me/#p/+{phone_number}`. When you open this link on your phone, it launches the Signal app and opens a conversation with that number — no contact saving required. On desktop, the link offers to open Signal Desktop or download it.

This is different from apps like WhatsApp or Viber that use deep links. The signal.me link is a regular web URL, which means it has a built-in fallback: if Signal is not installed, the page will prompt you to download it from signal.org/download/.

OPN Chat simplifies this process. Instead of manually constructing signal.me links, you:

1. **Enter the phone number** with the country code (for example, 1 for the US, 44 for the UK, 49 for Germany).
2. **Click "Open Chat in Signal"** — and you are taken directly to the conversation.

That is it. No sign-up, no data stored on any server. Everything runs inside your browser.

**Note:** Unlike WhatsApp or Viber, Signal does not support a pre-filled message parameter in its URL. The chat will open blank, and you type your message inside Signal.
