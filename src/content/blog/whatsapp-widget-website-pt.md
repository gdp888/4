## O que é um widget do WhatsApp?

Um widget do WhatsApp é um pequeno botão flutuante ou janela de chat incorporado a um site que permite aos visitantes abrir uma conversa do WhatsApp diretamente com o proprietário do site. Quando um visitante clica no widget, o WhatsApp se abre (no celular ou WhatsApp Web) com uma mensagem pré-preenchida pronta para enviar.

O design mais comum é um círculo verde flutuante no canto inferior direito da página, mas os widgets também podem aparecer como botões inline, janelas de chat pop-up ou elementos laterais.

## Por que adicionar um widget do WhatsApp ao seu site?

Os números falam por si. O WhatsApp tem mais de 2 bilhões de usuários ativos em todo o mundo, e em muitos países é o principal canal de comunicação. Eis por que um widget do WhatsApp faz sentido:

- **Comunicação instantânea** — Os visitantes podem entrar em contato com um clique, sem preencher formulários.
- **Maior conversão** — Estudos mostram que botões de chat do WhatsApp podem aumentar a geração de leads em até 40% em comparação com formulários de contato tradicionais.
- **Amigável para mobile** — O WhatsApp já está instalado na maioria dos smartphones, então a transição de navegação para chat é perfeita.
- **Confiança e familiaridade** — As pessoas confiam mais no WhatsApp do que em formulários de contato anônimos. Elas sabem que a mensagem vai direto para uma pessoa real.
- **Mensagens pré-preenchidas** — Você pode definir uma mensagem padrão para que os visitantes comecem a conversa com contexto, como "Olá, tenho interesse no seu produto."
- **Alcance global** — O WhatsApp funciona em todos os países, ideal para negócios internacionais.

## Adicionando o widget a diferentes plataformas

### WordPress
1. Vá em **Aparência > Editor de arquivos do tema** (ou use um plugin como "Insert Headers and Footers").
2. Cole o código do widget antes da tag `</body>` de fechamento em `footer.php`.
3. Alternativamente, use um widget de **HTML personalizado** em **Aparência > Widgets**.

### Site HTML
1. Abra seu arquivo HTML em um editor de texto.
2. Cole o código do widget antes da tag `</body>` de fechamento.
3. Salve e envie o arquivo para sua hospedagem.

### Wix
1. Abra o editor do seu site Wix.
2. Clique em **Adicionar Apps > Custom Code** (ou use o widget "Embed HTML").
3. Cole o código do widget e configure para aparecer em todas as páginas.

### Shopify
1. Vá em **Loja virtual > Temas > Editar código**.
2. Abra `theme.liquid` (ou `footer.liquid`).
3. Cole o código do widget antes da tag `</body>` de fechamento.
4. Salve o arquivo.

## Melhores práticas para widgets do WhatsApp

- **Mensagem padrão útil** — Pré-preencha algo como "Olá, tenho uma dúvida sobre..." para que os visitantes não fiquem olhando para uma tela vazia.
- **Posição no canto inferior direito** — É onde os usuários esperam ver widgets de chat. Não coloque em um lugar inesperado.
- **Não abra o chat automaticamente** — Deixe os visitantes clicarem quando estiverem prontos. Pop-ups automáticos irritam os usuários.
- **Teste no mobile** — Certifique-se de que o widget não sobreponha conteúdo importante ou botões em telas pequenas.
- **Responda rapidamente** — Um widget do WhatsApp cria a expectativa de respostas rápidas. Se não puder responder em minutos, configure uma mensagem de ausência.
