## What Text Formatting Does WhatsApp Support?

WhatsApp supports four text styles, each triggered by special characters placed around the text you want to format:

| Style | Symbol | Example | Result |
|---|---|---|---|
| **Bold** | Asterisk `*` | `*Hello*` | **Hello** |
| *Italic* | Underscore `_` | `_Hello_` | *Hello* |
| ~~Strikethrough~~ | Tilde `~` | `~Hello~` | ~~Hello~~ |
| `Monospace` | Three backticks `` ` `` | `` ```Hello``` `` | `Hello` |

You can also combine styles. For example, `*_Bold and Italic_*` produces ***Bold and Italic***.

## How to Format Text on Android

On Android, you have two methods: use the built-in menu or type the symbols manually.

**Using the menu:**
1. Type your message in the text field.
2. Tap and hold the text you want to format to select it.
3. Tap the three dots (overflow menu) in the top-right corner.
4. Choose Bold, Italic, Strikethrough, or Monospace.

**Typing symbols manually:**
Simply add the special characters before and after the text. For example, type `*important*` to get **important**. This method works in any text field and is faster once you remember the symbols.

## How to Format Text on iPhone (iOS)

On iPhone, the process is similar to Android but with a slightly different menu:

1. Type your message in the text field.
2. Tap and hold the text you want to format to select it.
3. Tap **BIU** in the popup menu.
4. Choose Bold, Italic, or Strikethrough.

For monospace, you need to type the three backticks manually: `` ```code``` ``.

## How to Format Text on WhatsApp Web and Desktop

On WhatsApp Web or the desktop app, the menu method works differently:

1. Type your message in the text field.
2. Select the text you want to format.
3. Right-click and choose from the formatting options, or use keyboard shortcuts:

| Format | Windows Shortcut | Mac Shortcut |
|---|---|---|
| Bold | Ctrl + B | Cmd + B |
| Italic | Ctrl + I | Cmd + I |
| Strikethrough | Ctrl + Shift + X | Cmd + Shift + X |

For monospace, there is no shortcut — use three backticks manually.

## Common Mistakes and Troubleshooting

**Formatting not working?** Make sure there are no spaces between the symbols and the text. `* Hello *` will not work — it must be `*Hello*`.

**Symbols showing instead of formatting?** This happens when the recipient is using a very old version of WhatsApp that does not support formatting. Ask them to update their app.

**Combining styles not working?** The inner symbols must be on the inside. `*~text~*` works, but `~*text*~` may not display correctly on all devices.

## Why Use Text Formatting in WhatsApp?

Text formatting is not just for decoration. It serves practical purposes:

- **Emphasis** — Bold important deadlines or instructions in group chats.
- **Corrections** — Use strikethrough to show what was changed: `~meeting at 3pm~ meeting at 4pm`.
- **Code sharing** — Monospace makes code snippets, URLs, and technical content readable.
- **Lists and structure** — Bold headings make long messages scannable.
- **Professional communication** — Well-formatted messages look more polished in business contexts.
