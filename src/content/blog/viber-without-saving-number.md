## How Does It Work?

Viber uses a deep link format: `viber://chat?number=%2B{phone_number}`. When you open this link, it launches a Viber conversation with that number — no contact saving required. The `%2B` is the URL-encoded `+` sign, which Viber requires before the country code.

OPN Chat simplifies this process. Instead of manually constructing deep links, you:

1. **Enter the phone number** with the country code (for example, 380 for Ukraine, 966 for Saudi Arabia, 66 for Thailand).
2. **Optionally write a message** that will be pre-filled in the chat.
3. **Click "Open Chat in Viber"** — and you are taken directly to the conversation.

That is it. No sign-up, no data stored on any server. Everything runs inside your browser.

**Important:** Unlike WhatsApp, Viber does not have a web fallback. Viber must be installed on your device for the deep link to work — on mobile, you need the Viber app; on desktop, you need Viber Desktop installed and running.
